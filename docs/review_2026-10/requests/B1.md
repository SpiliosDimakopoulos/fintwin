# B1 requests to other workstreams

## To B2 (`model/sd_model.py`): consume two calibration outputs (MM-F3, MM-F6)

B1 emits the keys only when the switch is on; with the keys absent (all v2 runs) the code below is exactly today's.

1. **MM-F6, current margin deviation.** Replace `m_dev = np.zeros(N, f)` with

   ```python
   m_dev = np.full(N, p.get("m_dev0", 0.0), f)
   ```

   (the first quarter then gets `rho_m * m_dev0 + sigma_m * e_m`, i.e. the deviation decays at `rho_m`).

2. **MM-F3, partial adjustment of fixed costs.** Before the loop:

   ```python
   lam_up = p.get("fixed_adj_lambda", 0.0)
   lam_dn = p.get("fixed_adj_lambda_down", lam_up)
   f_adj = p.get("fixed_adj_f", 0.0)
   F_t = np.full(N, p["F"], f)
   ```

   and replace `fixed = p["F"] * (1.0 + p["infl"]) ** (t + 1) * cut_mult` with

   ```python
   if lam_up > 0 or lam_dn > 0:
       F_t = F_t * (1.0 + p["infl"])
       rbar = rev / seasonal[(p["season0"] + t) % 4]  # deseasonalized; after the override / sales shock
       gap = f_adj * rbar - F_t
       F_t = F_t + np.where(gap > 0, lam_up, lam_dn) * gap
       fixed = F_t * cut_mult
   else:
       fixed = p["F"] * (1.0 + p["infl"]) ** (t + 1) * cut_mult
   ```

   With lambda = 0 this is the current recursion exactly; with lambda = 1 fixed costs are `f_adj` x revenue. It must
   use `rev` after `revenue_override`, so the transmission test's realized revenue drives the adjustment. B2's
   cost-cut loop (`cut_mult`) stays on top.
   `ma_flag` (1/0, only when the data layer supplies `acquisitions`) is for the evaluation split (C2), not the model.
