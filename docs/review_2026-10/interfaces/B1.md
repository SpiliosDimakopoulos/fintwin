# B1 (model calibration): interfaces

Status: draft, spec API final. The per-fix sections below are completed as the fixes land.

## `engine/fintwin/stochastic/spec.py`

```python
from fintwin.stochastic import spec
spec.spec()            # "v2-pre" | "v2-rev" | "v3"      (env FINTWIN_SPEC, default "v2-rev" = today's product)
spec.fixes()           # frozenset of active IDs, e.g. {"F1", "F5"}  (env FINTWIN_FIXES overrides)
spec.active("F5")      # bool; "MM-F5" is accepted too; unknown IDs are simply inactive
spec.fixed_share_prior()   # 0.35 for v2-pre and v3, 0.05 for v2-rev (the default of calibrate's assumptions)
spec.label()           # stamp for shard files, e.g. "v3" or "v2-pre[F4,F5]"
spec.LADDER            # ((step name, FINTWIN_FIXES value), ...) for FINTWIN_SPEC=v2-pre
with spec.using("v3", "+F9"): ...   # in-process override (ContextVar), takes precedence over the env
```

`FINTWIN_FIXES` syntax: `F5,F4` replaces the spec's default set; `+F9,-F3` edits it; `none` empties it; empty or unset
means the spec's defaults.

Default fix sets:
- `v2-pre`, `v2-rev`: none. Output is identical to rev3@20b2610 (test `tests/test_B1_parity.py`). They differ only in
  the default fixed-cost prior (35% / 5%) used when the caller passes no `fixed_share_prior`.
  Note: `research/experiments.calibrate` always passes 35% explicitly, so in research v2-pre = the main run.
- `v3`: F1 F2 F3 F4 F5 F6 F7 F8 F10 F12 F13 F14 M3. Off in v3 (§2 extensions, closed for H2): F9, M2.

Ladder (REVISION_PLAN_3 §0.2): run with `FINTWIN_SPEC=v2-pre` and `FINTWIN_FIXES` = `""`, `F5`, `F5,F4`,
`F5,F4,F1`, `F5,F4,F1,F2`, `F5,F4,F1,F2,F3`.

Other workstreams (B2, C*) may use their own IDs with `spec.active("M1")` etc.; add them to their spec's default set
by asking B1/the integrator (the sets live in `DEFAULT_FIXES`).
