# C1 (statistical inference): interfaces

All revision-2 keys of `research.json` are kept. Only keys and optional parameters are added. The one exception is `plan2.timing`: its bootstrap now runs on the full common sample instead of a 6000-row subsample (SW-12).

## Switches and environment

| Variable | Default | Effect |
|---|---|---|
| `FINTWIN_B_FAMILY` | 10000 | Bootstrap size of the pre-specified family (Romano–Wolf, SPA, MCS, year-block gains). Use a small value for a dry run. |
| `FINTWIN_B` / `FINTWIN_B_PANEL` | 2000 / 500 | The revision-2 bootstrap sizes (`stats.B`, `stats.B_PANEL`), now overridable. |
| `FINTWIN_B_LAD` | 199 | Firm-bootstrap size for the LAD encompassing standard errors. |
| `FINTWIN_DATA_LEGACY=1` | off | D8 reverts to revision 2: case gaps are measured from the petition, and in-bankruptcy firm-years are kept. |

## Signatures (all additions optional)

- `stats.main(cache, b_family=None)`.
- `stats.boot(..., seed=None)`. Each call creates its own Generator from `SEEDS["boot"]`; the module-global `RNG` is removed.
- `stats.bk_event(dates, origin, days=730, spans=None)`.
- New in `stats`:
  - `cases`, `in_bankruptcy`, `bankruptcy_filings`, `_spans`;
  - `stepm`, `spa`, `mcs`, `cluster_ols`, `two_way_mean`, `p_centered`;
  - `SEEDS`, `rng(name)`, `seeds_table()`, `B_FAMILY`, `B_LAD`.
- `transmission.section(rows, b, panel=True, b_family=None)`.
- `transmission.hybrid(df, var, firms, b, bounds="full")`. `"full"` is the revision-2 computation; `"train"` is E6.
- New in `transmission`:
  - `train_bounds`, `boot_losses`, `inference`, `wmedian`;
  - the constants `COMBOS`, `FORECASTERS`, `FAMILY`, `GAINS`.
- `plan2._combo(..., lo=None, hi=None)`. When `lo` and `hi` are None, the limits come from the training years.
- `plan2.boot_two_way(..., seed=None)`.
- New in `plan2`: `density_combos`.

## New keys in research.json

- `seeds`: a table of `{name: {seed, used_by}}`, plus `B`, `B_FAMILY_used` (R4).
- `samples.panel_in_bankruptcy_excluded` (D8). Panel rows also carry a boolean `in_bankruptcy`.
- `forecasts.<var>.<rw|ets>.dm_tG1`: two-way DM with t(G−1), the PSD flag, and the firm-only SE.
- `transmission.panel`:
  - `<var>.levels.<model>.mae`: unwinsorized mean error.
  - `<var>.hybrid.<a>_vs_<c>`: adds `est` (the full-sample estimate) and `p_centered`.
  - `<var>.hybrid_train`: the same layout as `hybrid`, with training-year limits, plus `mae` (unwinsorized) and `bounds`.
  - `<var>.encompassing` adds:
    - `all_two_way_tG1` (coef, t, p, p_firm, G, t_crit, psd);
    - `hln_tG1`;
    - `abs_loss_encompassing`: sign(e_a)(e_a−e_b), one-sided t(G−1);
    - `dm_abs`: absolute-loss DM;
    - `lad_levels`: median regression, firm-bootstrap SE.
  - `verdict.encompassing_p_twin_two_way_tG1`.
  - `inference`: the REVISION_PLAN_3 §2.1 family.
    - `family["<var>_<median|mean>_<model>_vs_N3"]`, 16 entries, each with diff, se, t, ci, p, p_romano_wolf, p_holm, reject_05 and reject_10. `diff` is the model's loss minus the 16q margin's loss, so a negative value means the model is better.
    - `spa["<var>_<loss>_<family|all>"]`: p_consistent, p_lower, p_upper.
    - `mcs["<var>_<loss>"]`: included, p_mcs, elimination_order, loss.
    - `gains.<var>["<a>_vs_<c>"]`:
      - gain_pct and gain_pct_ci_year_block;
      - p_year_block and p_year_block_positive;
      - dm_abs, dm_abs_raw, dm_sq (firm×year, t(G−1));
      - by_year, positive_years, n_years.
    - `gains.<var>.firm_year_ci`.
    - `n_<var>`, `test_years_<var>`, `lambda_<var>`, `B`.
  - Bootstrap schemes: `firm_year` (pigeonhole) for the family, SPA and MCS; `year` (year-block) for the gains. λ is re-chosen inside every resample.
  - Losses: the mean is winsorized at training-year limits; the median is unwinsorized.
- `plan2`:
  - `fcf_mechanism.<var>.train_bounds`, `capex_share_of_fcf_gain_train_bounds`, `capex_hypothesis_holds_train_bounds`.
  - `cash_hybrid.linear_pool`, `cash_hybrid.quantile_avg` (E11): lambda, skill_vs_rw, skill_ci, skill_twin_alone_vs_rw, accepted, ci_excludes_zero. Also `twin_crps_discretized_vs_sample`.
  - `timing.<ev>.twin_minus_no_loops` adds `est`, `p_centered`, `n`. The common sample is used.
- `stats.paired` output (also used by `distress`) adds `est` and `p_centered`.

## Added after the rebase onto rev3 (C2 / D requests)
- `stats.main(cache, b_family=None, out=None)`: `out` is the research.json path (default `stats.OUT`).
- New top-level keys of research.json, from C2's functions (each wrapped: a failure is stored as `{"error": ...}`):
  `density` (calibration.density_section), `liquidity` (distress.liquidity_section over distress.liquidity_frame(cache)),
  `credit_events` (distress.credit_section), `decision_scores` (distress.event_scores), `forecast_dm_by_horizon`
  (calibration.dm_by_horizon).
- `provenance` (D request 1): python, platform, numpy/pandas/scipy/statsmodels versions, git_sha (GITHUB_SHA or
  `git rev-parse HEAD`), uv_lock_sha256, snapshot_digest, spec (experiments.spec_label), FINTWIN_* env, run_id.
- `forecasts.<var>.n_ets_matched` and `n_all` (C2 request 8; `n` is unchanged = ETS-matched).
- E1 (C2 request 6): `transmission.point(st, key)` / `sens_point(path, var, e1)`. `transmission.frame` sets `T1_*`
  and `T0_*` to the spec's point (`twin_*_point`, `noloops_*_tot` under E1, else the v2 sum) and keeps the v2 sum in
  `T1sm_*`; `levels.T1_sum_of_medians` reports it. `plan2.frame` does the same for `twin_{cfo,fcf,ebitda,capex}`
  (v2 sums in `twin_*_sm`) and for `S_*_cfo` (`cfo_tot` under E1). Shards without the new keys give the v2 numbers.
