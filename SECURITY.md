# Security policy

FinTwin is a research project with no user accounts and no server that stores data: the dashboard is a static site, and the engine reads public SEC and FRED data.

If you find a security problem (for example in the optional API in `engine/fintwin/api.py`, the GitHub Actions workflows, or a dependency), please report it privately through [GitHub's private vulnerability reporting](https://github.com/SpiliosDimakopoulos/fintwin/security/advisories/new) rather than in a public issue. You should get a reply within a week.
